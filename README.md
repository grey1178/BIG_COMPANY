# 차세대 밴드 스케줄러 🎸

A single-page band rehearsal scheduler built with vanilla HTML/CSS/JS.

## Features

- 📅 **Vote** – Click calendar dates to mark which members are available. Donut chart visualizes participation per day.
- 📊 **Results** – Dates ranked by number of available members. Full-attendance days highlighted in green.
- 📢 **Notices & Songs** – Manage announcements and rehearsal song list (with Key & BPM info).
- 👥 **Members** – Add up to 8 members with custom photo, instrument, role, and color.

## Usage

Open `index.html` directly in any modern browser — no build step required.  
All data is persisted in **localStorage** automatically.

## Tech Stack

- Pure HTML5 / CSS3 / Vanilla JavaScript
- Google Fonts: Space Grotesk, Noto Sans KR
- No dependencies, no frameworks
